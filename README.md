# Maryam Hamdy — Portfolio

A minimal, editorial-style developer portfolio built with plain HTML and CSS and deployed with Vercel.

## Before deploying
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email address.
2. Replace/update the project placeholders as your portfolio grows.
3. Push the files to your GitHub `portfolio` repository.

No build step is required.
